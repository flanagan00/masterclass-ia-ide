# Laboratorio 1: Generación de Código Básico (QuickSort)

**Objetivo:** Comparar DeepSeek y Grok en la generación de un algoritmo QuickSort.

**Instrucciones:**
1. Abre `QuickSort.java` en VS Code/Cursor.
2. Usa Copilot/Tabnine/Codeium para generar el método `quickSort` desde el comentario `// Implement QuickSort`.
3. Alternativamente, pide a DeepSeek/Grok vía web: "Write a QuickSort method in Java."
4. Ejecuta el código con `mvn exec:java` y verifica el resultado: `[1, 1, 3, 4, 5]`.
5. Reflexiona: ¿La IA manejó casos extremos (array vacío)? ¿Cuál fue más rápida?

**Herramientas:** DeepSeek, Grok, Copilot, Tabnine, Codeium.
