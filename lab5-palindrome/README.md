# Laboratorio 5: Optimización y Explicación

**Objetivo:** Optimizar un verificador de palíndromos y evaluar explicaciones de IA.

**Instrucciones:**
1. Abre `Palindrome.java`.
2. Usa Copilot/Tabnine/Codeium para optimizar desde el comentario `// Optimize this`.
3. Pide a DeepSeek/Grok: "Optimize this palindrome check and explain it."
4. Ejecuta con `mvn exec:java` y verifica: `true`.
5. Reflexiona: ¿La IA redujo iteraciones? ¿Grok explicó mejor?

**Herramientas:** DeepSeek, Grok, Copilot, Tabnine, Codeium, ChatGPT, Claude.
