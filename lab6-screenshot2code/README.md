# Laboratorio 6: Screenshot2Code

**Objetivo:** Convertir un mockup en HTML usando Screenshot2Code.

**Instrucciones:**
1. Descarga un mockup simple (e.g., landing page con título y botón).
2. Usa Screenshot2Code localmente o vía su plataforma para generar HTML/CSS.
3. Compara con `index.html` proporcionado.
4. Abre `index.html` en un navegador para verificar.
5. Reflexiona: ¿El código generado es funcional? ¿Soporta frameworks como React?

**Herramientas:** Screenshot2Code, Lovable (para generación alternativa).
