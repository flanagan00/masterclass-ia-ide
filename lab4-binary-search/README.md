# Lab 4: Debugging with AI

**Objective:** Fix a bug in a binary search algorithm using AI.

**Instructions:**
1. Open `BinarySearch.java`.
2. Use Copilot/Tabnine/Codeium to suggest fixes from the comment `// Fix this`.
3. Ask DeepSeek/Grok: "Fix this binary search code."
4. Run the code with `mvn exec:java` and verify the result: `3`.
5. Reflect: Did the AI explain the error (incorrect index)? Was Grok clearer?

**Tools:** DeepSeek, Grok, Copilot, Tabnine, Codeium, ChatGPT, Claude.
