# Lab 3: Contract Test Generation

**Objective:** Generate contract tests with Pact using DeepSeek, Grok, and IDE extensions.

**Instructions:**
1. Open `UserController.java` and `UserContractTest.java`.
2. Use Copilot/Tabnine/Codeium to add a new test in `UserContractTest.java`.
3. Ask DeepSeek/Grok: "Generate a Pact consumer test for GET /user/{id}."
4. Run the tests with `mvn test`.
5. Reflect: Do the tests cover additional headers or states? Was DeepSeek more accurate?

**Tools:** DeepSeek, Grok, Copilot, Tabnine, Codeium, ChatGPT, Claude.
