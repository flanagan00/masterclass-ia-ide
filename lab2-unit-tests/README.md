# Lab 2: Unit Test Generation

**Objective:** Evaluate the generation of unit tests with JUnit using DeepSeek, Grok, and IDE extensions.

**Instructions:**
1. Open `ArraySum.java` and `ArraySumTest.java` in VS Code/Cursor.
2. Use Copilot/Tabnine/Codeium to generate new tests in `ArraySumTest.java` from the comment `// Add more test cases`.
3. Ask DeepSeek/Grok: "Write JUnit tests for sumArray."
4. Run the tests with `mvn test`.
5. Reflect: Did they cover cases like null? Were Grok's explanations clear?

**Tools:** DeepSeek, Grok, Copilot, Tabnine, Codeium, ChatGPT, Claude.
